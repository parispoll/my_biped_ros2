# Earlier analysis and comparison tools

Retained diagnostics and mathematical studies. These support earlier milestones and are not the main walking entry point.

| File | Responsibility |
|---|---|
| [ankle_diagnosis.py](ankle_diagnosis.py) | Planar static checks for a symmetric pair of ankle axes, independent of ROS. |
| [balance_repeats.py](balance_repeats.py) | Descriptive paired-repeat statistics; no confidence or stability claims. |
| [damping.py](damping.py) | Audit the constitutive viscous law separately from controller torque limits. |
| [resolution_study.py](resolution_study.py) | Summarize resolution changes versus repeat variation, without claiming an error bound. |
| [support_feasibility.py](support_feasibility.py) | Offline static support search; never used by the live controller. |
