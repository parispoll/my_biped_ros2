# Guides

Generate educational calculation documents and static guides.

Run tools from the workspace root with `python3 -m scripts.guides.<tool> --help`. Direct file execution also works.

| Tool | Purpose |
|---|---|
| [build_geometry_pdf.py](build_geometry_pdf.py) | Build the educational PDF from calculate_geometry_limits.py's saved results. |
| [make_statics_guide.py](make_statics_guide.py) | Regenerate the visual standing-load guide from the current robot model. |
