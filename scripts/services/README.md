# Services

Install the local panel login service. The stable start shell scripts remain one folder up.

Run tools from the workspace root with `python3 -m scripts.services.<tool> --help`. Direct file execution also works.

| Tool | Purpose |
|---|---|
| [install_force_panel_service.py](install_force_panel_service.py) | Install the loopback experiment panel as a login-started user service. |
